# ICBANQ Sales Portal - 2026-10-01

최신 작업 폴더 기준 배포용 소스입니다. 실제 IKI 연동 완료본이 아닙니다.

## GitHub에 올리기

1. ZIP을 압축 해제합니다.
2. GitHub Desktop에서 비공개(Private) 저장소를 만들거나 기존 저장소 폴더를 엽니다.
3. 압축 해제한 내용물을 저장소 안으로 넣습니다. 저장소 최상위에 package.json과 app 폴더가 보여야 합니다.
4. 변경 파일을 Commit한 후 Push/Publish합니다. ZIP 자체를 저장소에 올리는 것이 아닙니다.
5. 기존 저장소를 업데이트한다면 이전 파일과 새 파일의 차이를 확인합니다. 이 ZIP에서 제외된 예전 data 파일, 캡처, 비밀번호 파일이 저장소에 남아 있으면 별도로 제거해야 합니다.

## 배포 설정

- Next.js 프로젝트 소스입니다. 설치는 npm ci, 빌드는 npm run build입니다.
- 배포 서비스에서는 package.json이 있는 위치를 프로젝트 루트로 선택합니다.
- 로컬 실행: npm ci 후 npm run dev. 기본 포트가 사용 중이면 npm run dev -- --port 3011.
- 환경변수의 실제 값은 저장소에 올리지 말고 배포 서비스의 환경변수 설정에 등록합니다.
- .env.example의 your_..., change-this-secret 등은 예시입니다. 그대로 운영 설정에 넣지 않습니다.

## 반드시 확인

- 기본 demo 모드는 테스트 계정 전환 방식이며 본인 인증이 아닙니다. 회사 직원명·조직 및 내부 링크가 소스에 포함되어 있습니다. 비공개 GitHub 저장소를 사용하고 배포 사이트 자체의 접근도 제한하세요. GitHub가 비공개여도 배포 사이트가 자동으로 비공개가 되는 것은 아닙니다.
- 직원별 로그인에는 Supabase 설정과 계정 발급이 필요합니다. AUTH_SETUP.md를 확인하세요.
- 요청·월마감·수금 등의 영구 공용 저장에는 OPS_SHARED_STORAGE_URL 및 OPS_SHARED_STORAGE_SECRET 설정이 필요합니다. 서버리스 환경의 로컬 파일 저장은 영구 저장이 아닙니다. 저장소 미설정 상태에서는 화면 검토만 하고 실제 요청 등록·완료 처리를 운영하지 마세요.
- 수금 원본 자동 조회에는 OPS_RECEIVABLES_WEBAPP_URL 설정이 별도로 필요합니다.
- IKI 거래처 조회·세금계산서 발행·실제 매칭은 아직 연결되지 않았습니다. 샘플 기능을 실제 처리로 보고하지 마세요.
- 기존 실거래 데이터는 제외했습니다. data/trade-close-records.json은 앱에서 필요한 빈 초기 파일이며 처음 배포하면 실제 월마감 데이터는 보이지 않습니다. 배포 후 승인된 저장소를 연결하거나 데이터를 별도로 가져와야 합니다.

## 포함 / 제외

- 포함: app, public 이미지, 설정과 잠금 파일, Supabase 설정, 공용 저장소 스크립트, 검증 코드, 데이터 입력용 CSV 템플릿, 설정 안내.
- 제외: node_modules, .next, 캐시, 로그, 실제 .env, 기존 ZIP, 실거래 JSON/XLSX, ERP 캡처와 내부 HTML 도안.
- 개발 도안 HTML은 별도로 전달하세요. 사내 캡처가 포함되어 있으므로 public 폴더에 넣거나 공개 배포하지 마세요.
